Platinum Road: an offline guide and tracker for all 55 GTA VI PlayStation 5 trophies — a searchable checklist with saved progress, per-trophy counters and notes, a 6-stage roadmap to the platinum, a missables view, a Next-up planner, spoiler mode, dark theme, and progress export/import. Every guide is written in our own words from the official descriptions and names its sources; where a place or step is not pinned down by the official description, the guide says so instead of inventing it.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080.
